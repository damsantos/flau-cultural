# 🎭 FLAU Cultural

**FLAU Cultural** é um espaço dedicado ao teatro, cinema, artes visuais e ateliês de cerâmica, inspirado na energia criativa do Sesc Pompéia, mas com uma identidade totalmente autoral. Este repositório contém o código-fonte do site oficial, desenvolvido com **Quarto** e **RStudio** e hospedado no **GitHub Pages**.

🔗 **Site ao vivo:** [https://damsantos.github.io/flau-cultural/](https://damsantos.github.io/flau-cultural/)

---

## 🎨 Identidade visual

O design do site é uma fusão de três referências modernistas:

- **Bauhaus** → grade assimétrica, tipografia geométrica, funcionalidade.
- **Kandinsky** → círculos, linhas, tensão entre formas e composição.
- **Miró** → formas orgânicas, pontos, traços livres e cores vibrantes.

O resultado é um site que parece um **cartaz de exposição** — elegante, artístico e contemporâneo, sem parecer um museu dos anos 1920.
